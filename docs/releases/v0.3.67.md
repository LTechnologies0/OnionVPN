## Highlights

Baseline Profiles (AOT after install), ARM64 host builds without x86 QEMU, DNSCrypt/PAC/HTTP hardening, GrapheneOS MTE opt-in, and Status/Resources cleanup after tunnel stop.

## Performance

- Package Baseline + Startup profiles for Status, tunnel start, and Compose so ART compiles them on first run (ProfileInstaller — works sideloaded / Graphene / no Play).
- Seeded rules under `app/src/main/baselineProfiles/` and `baseline-prof.txt` / `startup-prof.txt`; regenerate optionally with `./gradlew :app:generateBaselineProfile` on a connected arm64 device.

## Build (ARM hosts)

- Native aarch64 `aapt2` override so Termux / ARM CI does not need QEMU for AGP’s Maven x86_64 aapt2.
- Helpers: `./scripts/configure-arm-host.sh`, `./scripts/gradlew-arm`, `gradle/arm-host.local.properties.example`.

## Security

- DNSCrypt + PAC: block private IPs / unsafe hostnames; limit PAC HTTP size and headers.
- `SecureTorHttp`: Tor-proxied HTTP with no redirects and modern TLS only.
- Stronger SOCKS DNS / DoH hostname checks.
- `android:memtagMode="async"` for ARM Memory Tagging Extension (GrapheneOS-friendly).

## Reliability / UX

- Resources UI no longer shows stale RSS/CPU after stop; chips only while the tunnel is up.
- Cleaner in-process VPN teardown on stop/destroy (fewer leftover tunnel threads with Always-On).

## Install

- Phones: use **`onionvpn-0.3.67-arm64-v8a.apk`** only.
- Obtainium APK filter: `arm64-v8a`.
- Verify: `sha256sum -c SHA256SUMS.txt`.
