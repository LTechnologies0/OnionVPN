## Highlights

Critical **audit-round-2 fixes** — native crash hardening, SOCKS sidecar robustness, SELinux-hardened /proc fallback, thread-safe recovery counter. Plus thread-safety and testability improvements.

## Critical Fixes

- **HevTProxyGate crash hardening**: native state tracking (`nativeInitialized` flag), pre-Start `TProxyStopService()` with 150ms grace period for stale thread cleanup, exponential backoff on consecutive failures (500ms -> 1000ms -> 2000ms, max 3 failures), failure counter reset on successful tunnel connection via `recordSuccess()`. Prevents SIGABRT in `libhev-socks5-tunnel.so` `netif_add` during init.

- **SOCKS sidecar early EOF fix** (`onionmasq-mobile::socks_sidecar`): 10-second handshake timeout prevents resource exhaustion; all read/write operations wrapped in `tokio::time::timeout`; graceful handling of EOF/timeout/connection reset as benign (debug log, not warn); 120s Tor circuit connect timeout; 30s DNS resolution timeout; robust `copy_flushing` handles broken pipe/connection reset.

- **ConnectionOwnerResolver SELinux hardening**: explicit `SecurityException` catch blocks on all four `/proc/net` scan paths (`/proc/net/tcp`, `/proc/net/udp`, `/proc/net/tcp6`, `/proc/net/udp6`) plus IPv4-mapped IPv6 fallback. Treat denials as "file not readable" and fall back gracefully to API 29+ `getConnectionOwnerUid` only. Debug logging when SELinux blocks access.

- **alwaysOnRecoveryAttempt thread-safety**: migrated from `@Volatile Int` to `AtomicInteger` with `incrementAndGet()` for atomic increment under concurrent Always-On/Blocking recovery scenarios.

- **TunDnsMux testability**: added public `isRunning` property for unit test verification.
