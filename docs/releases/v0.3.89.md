## Highlights

Hardened **Tor / DNSCrypt-over-Tor / OpenVPN-over-Tor** routing for security, stability, confidentiality, and anonymization (IsolateSOCKSAuth, Automap, SoftEther SNAT, bootstrap DNS).

## Tor / IsolateSOCKSAuth

- Per-UID and PAC SOCKS credentials require a per-tunnel session `-s{hex}` secret; bare `u{uid}/p{uid}` forge is rejected.
- onionmasq SOCKS sidecar: drop static `onionvpn`/`stream`; allow `uopenvpn`/`popenvpn`; require `-s` on `pac{uid}…`; reject `pac`+`resolver` alias and bare `uunknown`.
- Sidecar CONNECT refuses private / CGNAT / Automap / loopback destinations (parity with C Tor `ClientRejectInternalAddresses`).
- Little-t OpenVPN: NO-AUTH client dials a UID-gated `SocksAuthInjectingRelay` that injects `uopenvpn` into a dedicated Tor OPENVPN SessionGroup (`torOpenVpnIsolateSocksPort`).
- Apps SessionGroup on unix socket (little-t); sticky OPENVPN circuits across NEWNYM UID churn.

## DNSCrypt over Tor

- TunDnsMux: TCP/53 offloaded to DNS pool; Automap + DNSCrypt parity on TCP/53; upstream UDP with DNS ID + QR match.
- kotlin-DNSCrypt: cache key ignores DNS ID (rewrite on hit); 20s exchange timeout; concurrent UDP workers; AAAA → NODATA; disable PQ resume across Tor circuits; discard PQ ticket on reconfigure.
- NEWNYM: `stop()` keeps runtime ports so `applyPreferences` can restart; query cache always flushed (no cooldown skip).
- Bootstrap DoH: tighter timeouts, no OnionVPN User-Agent, Cloudflare + Quad9 only; refuse private/Automap A from SOCKS RESOLVE and DoH.
- DnsCryptResolver / DnsHostnameCache: reject Automap-range clearnet A (hijack defense); require QNAME match with ID retry.

## OpenVPN over Tor

- IFCONFIG publishes Via OVPN up when SNAT is ready; SNAT destination allowlist; `socks-auth.txt` owner-only; auth/log scrub.
- Firewall SOCKS/PAC plane: `ALLOW_OVPN` → **DENY** (never demote to Tor — prevents SoftEther TUN + Tor SOCKS dual egress).
- Unknown management NEED-OK → `cancel` (fail-closed); inject `auth-nocache`; shred credential files and wipe `runtime.ovpn` on stop.

## Firewall / LAN / hev

- Via LAN: bind uplink Network then `protect`; hev FromStr JNI; LAN clearnet dial; Automap divert / UID stamp hardening.
